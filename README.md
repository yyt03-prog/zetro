# Zotero 插件备份

为 Zotero 10.0.8 准备的三个插件安装包。这里仅备份插件文件、来源和校验值；没有论文 PDF、Zotero 数据库或个人配置。

| 插件 | 版本 | 安装包 | 上游发布页 | SHA-256 |
|---|---:|---|---|---|
| Translate for Zotero | 2.4.8 | [XPI](packages/translate-for-zotero-2.4.8.xpi) | [Release](https://github.com/windingwind/zotero-pdf-translate/releases/tag/v2.4.8) | `8145e9972c507f6baee93b93d2c2e8e7fe24388c58f2cebe0a37e29db5de26e6` |
| Better Notes for Zotero | 3.3.5 | [XPI](packages/better-notes-for-zotero-3.3.5.xpi) | [Release](https://github.com/windingwind/zotero-better-notes/releases/tag/v3.3.5) | `7dbe38c994608c5864ac76a33c500315db3361904b9f6f92bd5f78565c32c390` |
| Actions and Tags for Zotero | 2.6.3 | [XPI](packages/actions-and-tags-for-zotero-2.6.3.xpi) | [Release](https://github.com/windingwind/zotero-actions-tags/releases/tag/v2.6.3) | `6a97d76592a7a32b28749d993498cfe857c04bcdc79c77d212477e63569272be` |

在 Zotero 中打开“工具 → 插件”，点击齿轮，选择“从文件安装插件”，依次选取 `packages` 中的 `.xpi`。安装前请核对 Zotero 版本与插件版本的兼容范围；这些 XPI 中声明的兼容范围均包含 Zotero 10.0.8。

插件由各上游项目维护，许可证副本位于 [`licenses`](licenses)。本仓库仅保存对应发布版本的安装包；更新时请以各上游发布页为准。
